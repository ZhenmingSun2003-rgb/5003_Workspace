Aim and evaluation design

Predict the eight employment-status categories in Q279 using demographic and socioeconomic features. The shared baseline defines a stratified 60/20/20 Train/Validation/Test split, using seeds 5003 and 5005. Candidate configurations are selected by validation Macro F1, refitted on the complete 80% development pool, and evaluated on Test. Results below are generated during knitting.

Place the shared CSV beside this document, or set STAT5003_DATA_PATH to its location. The script checks the input checksum to preserve the agreed sample ordering. Required packages are rpart, knitr, and rmarkdown. Generated files are saved in STAT5003_C_baseline_results.

Reproducible analysis code

The following code includes univariate EDA, class imbalance, an optional raw-data missingness audit, and decision-tree fitting. The search covers three feature specifications and 54 configurations of complexity parameter, maximum depth and minimum split size. All candidates use the full initial training partition. Numeric preprocessing is learned only from the fitting partition; categorical levels follow the shared codebook conventions.

read_data <- function(path, cols = NULL) {
  # Read only requested columns to keep memory low; preserve code strings.
  header <- names(read.csv(path, nrows = 0, check.names = FALSE))
  if (!is.null(cols)) {
    absent <- setdiff(cols, header)
    if (length(absent)) stop("Missing columns: ", paste(absent, collapse = ", "))
  }
  classes <- if (is.null(cols)) "character" else ifelse(header %in% cols, "character", "NULL")
  read.csv(path, colClasses = classes, check.names = FALSE,
           na.strings = c("", "NA", "NaN"), stringsAsFactors = FALSE)
}

stratified_indices <- function(y, fraction, seed) {
  set.seed(seed)
  groups <- split(seq_along(y), y, drop = TRUE)
  sort(unlist(lapply(groups, function(ii) sample(ii, floor(length(ii) * fraction))),
              use.names = FALSE))
}

# VERBATIM baseline eight-class evaluator:
evaluate_8class <- function(truth, pred, show_confusion = TRUE) {
  tr <- factor(as.character(truth), levels = TARGET_LABELS)
  pr <- factor(as.character(pred), levels = TARGET_LABELS)
  if (anyNA(tr) || anyNA(pr)) stop("Unknown/missing prediction class")
  cm <- table(True = tr, Predicted = pr)
  tp <- diag(cm)
  support <- rowSums(cm)
  predicted <- colSums(cm)
  precision <- ifelse(predicted > 0, tp / predicted, 0)
  recall <- ifelse(support > 0, tp / support, 0)
  f1 <- ifelse(precision + recall > 0,
               2 * precision * recall / (precision + recall), 0)
  by_class <- data.frame(Class = TARGET_LABELS, Support = as.integer(support),
                         Precision = round(precision, 4), Recall = round(recall, 4),
                         F1 = round(f1, 4), row.names = NULL)
  overall <- data.frame(Macro_F1 = mean(f1),
                        Weighted_F1 = sum(support * f1) / sum(support),
                        Accuracy = sum(tp) / sum(cm))
  if (show_confusion) print(cm)
  list(overall = overall, by_class = by_class, confusion = cm)
}

  Education=as.character(0:8),SocialClass=as.character(1:5),
  IncomeBracket=as.character(1:10),Savings=as.character(1:4),

numeric_value <- function(v) {
  x <- suppressWarnings(as.numeric(as.character(v)))
  x[!is.finite(x)] <- NA_real_
  x
}
learn_recipe <- function(raw) {
  num <- lapply(NUMERIC_KEYS,function(k) numeric_value(raw[[k]]))
  med <- vapply(num,function(x) if(all(is.na(x))) 0 else median(x,na.rm=TRUE),0.0)
  filled <- Map(function(x,m) {x[is.na(x)] <- m;x},num,med)
  mu <- vapply(filled,mean,0.0)
  sigma <- vapply(filled,sd,0.0)
  sigma[is.na(sigma)|sigma==0] <- 1
  list(median=med,mean=mu,sd=sigma)
}
apply_recipe <- function(raw,r) {
  out <- data.frame(Outcome=factor(as.character(raw$Outcome),levels=TARGET_LABELS))
  for (nm in names(NUMERIC_KEYS)) {
    x <- numeric_value(raw[[NUMERIC_KEYS[[nm]]]])
    missing <- is.na(x)
    x[missing] <- r$median[[nm]]
    out[[nm]] <- (x-r$mean[[nm]])/r$sd[[nm]]
    out[[paste0(nm,"_missing")]] <- as.integer(missing)
  }
  out$Age_sq <- out$Age^2
  for(nm in names(CATEGORY_KEYS)) {
    v <- trimws(as.character(raw[[CATEGORY_SOURCES[[nm]]]]))
    v[is.na(v)|!(v %in% CATEGORY_KEYS[[nm]])] <- "Missing"
    out[[nm]] <- factor(v,levels=c(CATEGORY_KEYS[[nm]],"Missing"))
  }
  out
}

fit_tree <- function(raw_prepared, spec, cp, maxdepth, minsplit) {
  rpart::rpart(reformulate(SPECIFICATIONS[[spec]], response = "Outcome"),
    data = raw_prepared, method = "class", parms = list(split = "gini"),
    control = rpart::rpart.control(cp = cp, maxdepth = maxdepth, minsplit = minsplit, xval = 0))
}

Interpretation and limitations

Legacy pre-correction interpretation: the fixed zero-prediction claim below belongs to the original map; consult newly generated class counts and recall for the corrected run.

Inspect the per-class results alongside Macro F1: the tested configuration does not predict Part-time, Unemployed or Other, giving zero recall for these classes. The fitted leaf decisions favour the remaining classes. Class imbalance and insufficient separation under the selected features and tree constraints are plausible contributing factors; the results do not establish a single cause.

The shared A1 CSV was already imputed before splitting, so this analysis avoids additional fitted-preprocessing leakage but cannot remove the inherited risk. The country-income mapping is verified against the frozen FY2021 historical table; it is not survey-year-specific and NIR inherits UK High. Original missingness cannot be reconstructed from the imputed CSV; the optional audit is skipped unless original data are supplied. Random individual-level holdout does not establish performance in unseen countries or future years. This document is a model contribution to the group report, not the complete final submission.
