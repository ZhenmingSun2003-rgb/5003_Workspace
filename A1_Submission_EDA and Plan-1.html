Introduction

1.Dataset Selection:

This project uses the cross-national dataset from Wave 7 of the World Values Survey (WVS7), containing approximately 97,000 observations and more than 600 variables. The dataset is suitable for this classification task because it is large, complex, messy, and contains a multi-class outcome. It includes numerical and categorical variables, special missing-value codes, country-specific variables, and externally derived indicators.

2.Research Topic and Question:

The target variable is Q279, representing employment status across eight categories: full-time employee, part-time employee, self-employed, retired or pensioned, housewife not otherwise employed, student, unemployed, and other. The research question is: To what extent can an individual’s demographic characteristics, educational background, and socioeconomic circumstances be used to predict their employment status? Relevant predictors include age, gender, marital status, educational attainment, income level, and perceived social class.

3.Motivation and Significance:

Employment status is related to income, labour-market participation, social protection, and career development. Understanding differences across employment categories may help identify groups facing unemployment or labour-market participation difficulties and support more targeted employment assistance and resource allocation. As the WVS is observational survey data, this project focuses on predictive relationships rather than causal effects.

Data Cleaning and Preprocessing

Data cleaning was conducted according to the official WVS Wave 7 codebook. Special missing-value codes and invalid values were converted to NA, and variables were divided into four groups according to their coding structures.

1.Outlier and Invalid-Value Treatment:

The first group contains basic-information variables such as country, survey year, sampling information, and survey weights. Because these variables use different coding systems, only their missingness was examined.

The second group contains fixed-choice questionnaire variables. Valid values were defined according to the official codebook, and values outside the corresponding valid ranges were converted to NA.

The third group contains fill-in and country-specific variables, such as age, year of birth, household size, and number of children. Because these variables have different meanings and valid ranges, statistical outlier rules such as IQR were not applied automatically.

The fourth group contains derived indices and external indicators. Variables with officially defined theoretical ranges were checked against those ranges, while variables without strict boundaries were examined using their observed ranges and missingness.

Invalid values were replaced at the individual-cell level rather than deleting entire observations.

2.Missing-Value Treatment

After invalid values were converted to NA, variables with more than 50% missing values were removed.

The remaining missing values were handled as follows: Group 1: replaced with "Unknown"; Group 2: imputed using the mode; Group 3: replaced with "Unknown"; Group 4: imputed using the mode.

fixed_invalid_summary <- do.call(
  rbind,
  lapply(names(fixed_question_groups), function(group_name) {

    # Extract the number of valid categories from the group name
    category_number <- as.numeric(
      sub(" categories", "", group_name)
    )

    do.call(
      rbind,
      lapply(
        fixed_question_groups[[group_name]],
        function(variable_name) {

          # Define valid codes according to whether the variable begins at 0 or 1
          if (variable_name %in% zero_based_variables) {
            valid_values <- 0:(category_number - 1)
          } else {
            valid_values <- 1:category_number
          }

          # Extract the current values of the variable
          current_values <- wvs_clean[[variable_name]]

          # Identify non-missing values outside the official valid codes
          invalid_values <- current_values[
            !is.na(current_values) &
              !(current_values %in% valid_values)
          ]

          # Create a summary of invalid values for the current variable
          data.frame(
            variable = variable_name,
            category_group = group_name,
            valid_codes = paste(
              valid_values,
              collapse = ", "
            ),
            invalid_count = length(invalid_values),
            invalid_values = paste(
              sort(unique(invalid_values)),
              collapse = ", "
            ),
            row.names = NULL
          )
        }
      )
    )
  })
)

# Define a helper function for creating valid-range rules
make_range_rules <- function(variables, lower, upper) {
  data.frame(
    variable = variables,
    lower = rep(lower, length(variables)),
    upper = rep(upper, length(variables)),
    row.names = NULL
  )
}

# 4. Define a function for mode imputation

fill_with_mode <- function(x) {

  # Extract all non-missing values
  observed_values <- x[!is.na(x)]

  # Return the original variable if all values are missing
  if (length(observed_values) == 0) {
    return(x)
  }

  # Calculate the mode while preserving the original data type
  unique_values <- unique(observed_values)

  mode_value <- unique_values[
    which.max(
      tabulate(
        match(observed_values, unique_values)
      )
    )
  ]

  # Replace missing values with the mode
  x[is.na(x)] <- mode_value

  return(x)
}

Model Plan

1. Modelling Strategy:
The EDA suggests that employment status cannot be explained by a single predictor. Age clearly distinguishes Student and Retired respondents, while gender is particularly informative for Housewife respondents. However, substantial overlap remains among other categories, suggesting that predictor combinations, interactions, and nonlinear relationships may be important.

Q279 is highly imbalanced, with the largest class approximately 30 times the size of the smallest. Therefore, model evaluation will not rely on accuracy alone. Models with different assumptions and levels of flexibility will be compared based on overall performance.

2. Feature Strategy:
Country-level Socioeconomic Context: The EDA shows clear variation in employment-status distributions across countries. However, including Country would introduce more than 60 categorical levels, increasing model complexity and potentially affecting distance-based methods such as kNN. Instead, an Income_Group feature will be created using the World Bank’s country income classification: Low income, Lower-middle income, Upper-middle income, and High income. This provides a lower-dimensional representation of country-level socioeconomic context. Raw Country will therefore be excluded. Since the classification is independent of Q279, it does not introduce target leakage. Other Predictors: The final predictors will focus on demographic, educational, and socioeconomic variables identified during the EDA. Categorical variables will be appropriately encoded and numerical variables scaled where required. Survey weights will not be used because the objective is individual-level prediction rather than population-level inference.

3. Model Selection:
1.Multinomial Logistic Regression: An interpretable linear baseline for the eight-class problem, but may not capture important interactions or nonlinear relationships. 2.Linear Discriminant Analysis (LDA): An alternative linear and distribution-based benchmark, although its distributional and covariance assumptions may not suit the mixture of categorical and numerical predictors. 3.k-Nearest Neighbours (kNN): Tests whether respondents with similar characteristics have similar employment statuses. It is non-parametric but sensitive to scaling, the choice of k, and distance measure, and may be computationally expensive. 4.Support Vector Machine (SVM): Tests whether more flexible decision boundaries improve classification of overlapping categories. Its main limitations are computational cost and parameter tuning. 5.Decision Tree: Can capture conditional relationships, interactions, and nonlinear patterns, such as the effects of age and gender identified in the EDA. However, a single tree may be unstable and prone to overfitting.

4. Evaluation Plan:
Primary Metric: Macro F1: Macro F1 will be the primary metric because Q279 is strongly imbalanced. It gives equal weight to all eight classes and prevents large classes from dominating evaluation. Secondary Metrics: Weighted F1 and Accuracy will also be reported. Weighted F1 reflects overall performance while accounting for class frequency, while Accuracy will be used as a supplementary measure. Confusion matrices and per-class Precision, Recall, and F1 will also be examined, particularly for minority and frequently confused categories.

5. Train-Test Strategy:
A stratified train-test split will be used to approximately preserve the class distribution of Q279 in both sets. Because the objective is individual-level prediction rather than generalisation to unseen countries, the data will not be split by country. Raw Country will be excluded, while Income_Group will be retained as the broader socioeconomic feature.

6. Model Comparison and Final Selection:
All five models will be evaluated using the same test set and framework. Final selection will consider: 1. Macro F1. 2. Weighted F1 and Accuracy. 3. Minority-class performance. 4. Confusion-matrix patterns. 5. Interpretability and computational cost. The final model will be selected based on the balance between predictive performance, minority-class performance, interpretability, and efficiency.

7. Backup Plan:
If SVM or kNN is too computationally expensive, parameter tuning will be simplified or a stratified subset of the training data will be used during development. If minority-class performance is poor, confusion matrices and per-class F1 scores will be examined before further modelling decisions. If several models perform similarly, the simpler and more interpretable model will be preferred.

8. Timeline:

  1. Model Preparation: Finalise predictors, create Income_Group, exclude Country, prepare encoding and scaling, and perform the stratified train-test split. 2. Baseline Models: Fit Multinomial Logistic Regression and LDA. 3. Flexible Models: Fit and tune kNN, SVM, and Decision Tree. 4. Model Evaluation: Calculate Macro F1, Weighted F1, Accuracy, confusion matrices, and per-class metrics. 5. Final Model Selection: Compare predictive performance, minority-class performance, interpretability, and computational cost. 6. Final Reporting: Relate modelling results to the EDA and research question, and explain the main predictors and model performance.
